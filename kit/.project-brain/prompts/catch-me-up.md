# Prompt: catch me up

Use when you come back to the project after days or weeks.

---

I'm coming back to this project after a while. Using only `.project-brain/`
(and the code only to confirm), brief me in under a page:

1. **What this system is** — 3 lines.
2. **The map** — the container diagram from `architecture.md` (re-draw it if the
   code has drifted, and say what drifted).
3. **What changed recently** — the last 5–10 entries of `feature-history.md`,
   grouped by theme, with links to the records.
4. **Decisions to remember** — ADRs that constrain the next piece of work.
5. **Open risks and loose ends** — from `architecture.md` and recent records.
6. **Where to start** — the 3 files I should open first for <optional: TASK>.
